# CV / LinkedIn Project Entry

**E-commerce Customer Analytics & Segmentation | Python, Pandas, Scikit-learn, RFM, K-Means**

- Cleaned and validated 900+ reliable e-commerce order records extracted from a PDF business export while preserving customer privacy.
- Performed exploratory analysis of revenue, channels, payment behaviour and order status.
- Built customer-level RFM features and applied log transformation, standardization and K-Means clustering.
- Evaluated multiple cluster sizes using inertia and silhouette analysis and selected a six-segment business solution.
- Identified a high-value segment of 73 customers contributing approximately 59% of analyzed revenue, highlighting a strong customer-retention opportunity.
